# 词境爽文局 · 无痛背词实验室

一个原创的中文情景化背词网页产品。灵感来自“小红书商品详情页”的竖版卡片、轻量剧情和低门槛学习路径，但页面、文案、视觉与互动内容均为原创。

## 功能

- 4 幕原创剧情词场，共 48 个英语词汇，作为产品体验预告。
- 3,632 条雅思备考词条全部进入 22 个主题剧情篇章。
- 每个主题篇章按 12 个词拆成连续场景；每个词都以故事里的高亮线索出现。
- 点击剧情线索查看音标、释义、剧情英文、原创记忆钩子，并点亮本词。
- 支持按篇章、剧情标题或单词搜索，按剧情顺序、词量和未点亮优先排序。
- 使用 `localStorage` 保存整套词库的点亮进度，并提供动态剧情复盘题。
- 今日复盘 3 道选择题。
- 响应式布局，支持手机和桌面浏览器。

## 词库来源

雅思词库数据来自公开项目 [LynnShaw/vocabulary_for_ielts](https://github.com/LynnShaw/vocabulary_for_ielts)，包含单词、音标、中文释义和主题章节；本项目在页面中保留来源说明。剧情、记忆钩子、复盘题和交互设计为本项目原创。

## 本地运行

无需安装依赖，直接打开 `index.html` 即可；也可以运行：

```bash
python3 -m http.server 4173
```

然后打开 <http://localhost:4173>。
