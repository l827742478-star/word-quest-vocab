# 词境爽文局 · 无痛背词实验室

一个原创的中文情景化背词网页产品。灵感来自“小红书商品详情页”的竖版卡片、轻量剧情和低门槛学习路径，但页面、文案、视觉与互动内容均为原创。

## 功能

- 4 幕剧情词场，共 48 个英语词汇。
- 点击单词卡片查看释义和记忆钩子。
- 今日复盘 3 道选择题。
- 使用 `localStorage` 保存点亮进度和复盘成绩。
- 响应式布局，支持手机和桌面浏览器。

## 本地运行

无需安装依赖，直接打开 `index.html` 即可；也可以运行：

```bash
python3 -m http.server 4173
```

然后打开 <http://localhost:4173>。
