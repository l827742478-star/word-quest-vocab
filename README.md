# 词境爽文局 · 无痛背词实验室

一个原创的中文情景化背词网页产品。灵感来自“小红书商品详情页”的竖版卡片、轻量剧情和低门槛学习路径，但页面、文案、视觉与互动内容均为原创。

## 功能

- 4 幕剧情词场，共 48 个英语词汇。
- 点击单词卡片查看释义和记忆钩子。
- 内置 3,632 条雅思备考词条，覆盖 22 个主题章节。
- 支持英文/中文/主题搜索、主题筛选、A-Z 排序、未点亮优先和分页浏览。
- 雅思词库卡片支持逐词点亮，并使用 `localStorage` 保存进度。
- 今日复盘 3 道选择题。
- 响应式布局，支持手机和桌面浏览器。

## 词库来源

雅思词库数据来自公开项目 [LynnShaw/vocabulary_for_ielts](https://github.com/LynnShaw/vocabulary_for_ielts)，包含单词、音标、中文释义和主题章节；本项目在页面中保留来源说明。剧情、记忆钩子、复盘题和交互设计为本项目原创。

## 本地运行

无需安装依赖，直接打开 `index.html` 即可；也可以运行：

```bash
python3 -m http.server 4173
```

然后打开 <http://localhost:4173>。
